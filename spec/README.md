## Version note

The current normative reference is v0.2.2 ([Limnalis-v0.2.2.md](Limnalis-v0.2.2.md)); the v0.2.1 documents are the prior spec edition, retained for history. The full expression grammar (Appendix A.8), which the consolidated v0.2.2 and v0.2.1 specs defer to the un-vendored v0.2 specification for, is now available in the reconstructed spec ([Limnalis-v0.2.2-reconstructed.md](Limnalis-v0.2.2-reconstructed.md)) — with the caveat that it is a reconstruction, not the lost original (see the [recovery notes](Limnalis-v0.2.2-recovery-notes.md)).

Reader precedence: for prose semantics, canonical consolidated spec > reconstruction > v0.2.1 edition. **For AST shapes specifically, this ordering inverts:** the seam audit found the consolidated edition's Appendix A.9 to be the least reliable description of the canonical AST — the vendored JSON Schemas (`schemas/`), then the reconstruction's AST listing, are more faithful (e.g. A.9's phantom `ClaimNode.eval` field, its orphan `TermSpecNode` type, and its optional `frame?: FrameNode` are all contradicted by the schema and reconstruction together). Known errors in the vendored set are recorded, with evidence, in the [errata](Limnalis-v0.2.2-errata.md) — vendored documents themselves are never edited. Deviations and extensions of the implementation are documented in [docs/compatibility_and_deviations.md](../docs/compatibility_and_deviations.md).
